KAZFACE PWA — файлы приложения

Содержимое:
- index.html — твой KAZFACE PRO 4.0 с установкой PWA
- manifest.webmanifest — название, иконка и режим приложения
- sw.js — кэширование оболочки для повторного запуска
- icons/ — иконки KAZFACE

Установка:
1. Размести ВСЕ файлы и папку icons на одном HTTPS-хостинге, сохранив структуру.
2. Открой опубликованный адрес на телефоне.
3. Android: нажми «УСТАНОВИТЬ» или меню браузера → «Установить приложение».
4. iPhone: открой сайт в Safari → «Поделиться» → «На экран Домой» → «Добавить».

Важно:
- PWA требует HTTPS (или localhost для тестирования).
- Профили пока хранятся в localStorage конкретного браузера/устройства. Это не общая онлайн-база и не синхронизируется автоматически между телефоном и ПК.
- Офлайн-кэш сохраняет оболочку сайта, но функции, которым нужен интернет, без сети работать не будут.
- Это не официальное приложение FACEIT и не подключается к Steam/FACEIT.
